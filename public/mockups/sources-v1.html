S2The state vocabulary, and what each one costs

One state per source, derived from two independent facts: has it been imported, and does the extraction still match what it was extracted from. Every state names the action it implies and what that action spends. This is the backlog's “sources freshness icons” item, answered.

S3Bulk path — lorebooks and characters

Your rule: lorebooks go in wholesale. Selection is a checkbox rail, select all lives on the group header, and the dock states the cost in model calls before you commit. You asked for a confirm only above a threshold, so small batches import straight from the dock and larger ones raise the sheet.

S4Curate path — chat summaries open where they sit

Your other rule: chat summaries need manual review, curation, and editing before they go in. The first draft made that a separate screen you paged through. It does not need to be. On your instance a chat summary runs about 1,800 characters — roughly 440 tokens, and under 800 at the worst — so the whole thing fits inline. The row expands where it sits, you read it, edit it if it needs it, import it, and the list is still around you.

S5The repair surface — where 45 blocked drafts get unstuck

This is the screen you actually needed today, and it lives in Sources with the review queue linking to it. Blocked drafts group by cause, not by source, because the cause determines both the fix and the bill. The wording here is not hypothetical: it is what I measured on your instance.
