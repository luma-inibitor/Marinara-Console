Apply sheet — how big should the number be?

Pick a size, then pick an arrangement. Every example below is identical except for the number at the top, so that is the only thing you are judging.

§0 Every text size we have

Every text size in the app, biggest first. The thing to notice is the last row: we have nothing bigger than 17px. So the largest thing any screen can say is barely bigger than ordinary body text. That is why the sheet looks flat however you arrange it — there is no big size to reach for.

Everything sits between 9.5px and 17px. When every size is nearly the same, the only ways left to make something look important are bold and colour. That is the flatness you spotted.

Each box is 458px wide, which is how much room the number really gets on your phone, and the little grey count on the left eats a bit more — so this test is slightly harsher than reality. Anything that fits here will fit there. The result: 14, 24 and 32 all cope with four digits. 44px spills onto a second line at every single number, even "9". So 44 is out because I measured it, not because I dislike it.

§2 How should it be arranged?

All three are 32px, so size is not what you are judging here. The question is whether the sheet should open with a number or with a sentence.

E · words on the same line — same as C

Reads as one phrase. The widest of the three, so a four-digit number gets close to the edge.

F · words underneath

Stays narrow no matter how big the number gets. But it breaks one phrase into a number plus a caption, so "memory writes" stops being part of the sentence and turns into a tag.

G · a sentence, with the number enlarged

What Apply will send ×

Apply will write 9 memories to the vault.

2 new memories·4 text changes·3 metadata changes

Tells you what is about to happen instead of just giving you a number, which suits a confirm screen. The problem is that a big number stuck in the middle of a sentence never lines up properly, and it gets worse as the number grows.

§3 My recommendation

C and E — 32px, words on the same line. It is the only option that is both obviously the headline and still reads as one phrase. F is tempting because it stays narrow, but turning "memory writes" into a tag is exactly how the old sheet ended up with three bare numbers stacked in a column and no way to tell what they counted.

If 32px is too loud on your phone, 24px is the same design a bit quieter. That is a number we can nudge later, not a decision to redo.
