Button ladder v2 — rebasing primary and secondary

Four ways to build the hierarchy once you accept what near-black surfaces can and cannot do.

measured · tokens only · 44px

1 · The two constraints, measured

Containers have almost no range. Against the canvas, the accent fill stands off at 7.24:1 and every neutral surface and border we own falls between 1.07:1 and 1.87:1. There is no middle to put a tier in, which is why v1's four tertiary candidates all collapsed into either "second primary" or "ghost".

And accent ink is dim. This is the part I had backwards last time:

00 ink brightness against the canvas

Apply--text · 15.78:1 Apply--accent · 7.24:1 Apply--text-dim · 6.41:1 Apply--text-faint · 3.88:1

An accent label is less than half as bright as a neutral one, and only a hair brighter than dim. So any ladder that ranks accent ink above neutral ink is inverted on the only axis the eye actually reads at a glance. My last message proposed exactly that. It was wrong.

What survives: hierarchy has to be carried by the box first, then ink brightness — and accent stops being an emphasis step at all. That is also what DESIGN.md §1 already says accent is for: focus, selection, links. Options A and B below take that seriously. C is the ladder I proposed in prose, drawn so you can see the inversion. D removes the fill entirely.

2 · Four rebases

A three tiers · box, then brightness

primary box 7.24 · ink 7.12 secondary box 1.87 · ink 15.78 ghost box — · ink 6.41
  • strength Monotonic on both axes. Each step is visibly quieter than the one before, with no argument required.
  • strength Three appearances is exactly what 119 buttons in this repo already produced organically. Nothing has ever needed a fourth.
  • strength Secondary's border moves --edge → --edge-strong (1.35 → 1.87), so the box stops being invisible, and the fill is dropped so it stops pretending to be a surface.
  • weakness No home for an action that is secondary in rank but should not carry a full box.

B four tiers · box, then brightness

primary box 7.24 · ink 7.12 secondary box 1.87 · ink 15.78 tertiary box 1.35 · ink 6.41 ghost box — · ink 6.41
  • strength Still monotonic: the box weakens and the ink dims together, so the fourth step is a real step.
  • strength Accent stays unspent below primary, so pressed and selected keep their meaning.
  • weakness Tertiary and ghost differ only by a 1.35:1 border — the weakest distinction in any option here.

C four tiers · accent as the second step (the one I proposed — shown to be rejected)

primary box 7.24 · ink 7.12 secondary box 1.87 · ink 7.24 tertiary box 1.35 · ink 15.78 ghost box — · ink 6.41
  • weakness The third step is the brightest label in the row (15.78 vs secondary's 7.24). Read the row quickly and "Export backup" wins.
  • weakness Spends accent on rank, which DESIGN.md §1 reserves for focus and selection.
  • note Included only so the inversion is visible rather than asserted.

D no solid fill · the compressed band

primary box 1.19 fill / 7.24 border · ink 7.24 secondary box 1.87 · ink 15.78 tertiary box 1.35 · ink 6.41 ghost box — · ink 6.41
  • strength No color slabs anywhere — the most instrument-panel reading of the set, and closest to the "data is the ornament" line in §1.
  • strength Bringing the top down makes four tiers easy, because the whole range compresses.
  • weakness Primary's label is now 7.24 against secondary's 15.78 — the same inversion as C, just one row up.
  • weakness The wash is the established pressed signal; primary would be permanently wearing it.

4 · What accent is freed up to mean
