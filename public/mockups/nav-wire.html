N2Desktop — three ways to divide the bar

The four views are settled. What differs is where scope lives and whether the counts have a home.

N3The scope picker — four ways to telescope

Your upstream flow is character → chat (or all) → branch (or all), with all available at every level. That is a cascade where each level filters the next, so the question is only how much of the cascade you can see at once. The screenshot arrived: upstream is C — three stacked labelled menus in a card, with the counts line directly beneath. So C is the floor, not the ceiling. A, B and D are the ways to beat it.

N4Mobile — the same map, repositioned

The console already spends its bottom bar on tools, and the budget is one top region and one bottom region, so the four views cannot become a second bottom bar. They become a tab row under the header. The open question is whether scope shares the header line or takes its own.

Counts belong to scope because scope is what changes them. Index health is either fine or urgent: when it is fine it should say nothing at all, and when it is not it deserves a real banner, not a word in a corner. The instance belongs beside the tool name, because it is an identity, not a metric.
