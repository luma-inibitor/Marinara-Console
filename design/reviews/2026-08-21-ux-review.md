# UX review — Memory tool, 2026-08-21

Five parallel reviewers over the feat/memory-tool build at `:7875` (local mock
corpus): **[INT]** Review Queue interaction deep-dive (19 findings), **[LNK]**
cross-surface linkage (16), **[VIS]** visibility/feedback (26), **[MOB]**
mobile/a11y/design-compliance (18), **[COD]** dead-affordance code scan (20).
99 raw findings, deduplicated below to 58 unique items in 7 clusters, plus
Eli's mobile round 2. Evidence: /tmp/uxrev-{a,b,c,d}/ screenshots; file:line

Priorities: **P0** correctness of the decision/apply core + the mobile
blocker · **P1** structural UX (navigation, density, visibility of computed
state) · **P2** polish, copy, linkage completeness, a11y depth · **P3**
design work gated on the owner interview. Owner re-triage pending.

## A · Decision/apply correctness — P0

1. **Cross-claim edit-text leak** [INT critical] — ClaimDetail isn't keyed by
   row; `drafts["__text"]` survives row switches, so claim A's edited text
   appears in claim B's editor and can be saved onto it. Fix: `key={row.key}`.
2. **Stale preflight vs local decisions** [COD high + INT high] — Apply uses a
   debounced, unawaited preflight snapshot: a keep→drop flip inside 500ms sends
   a just-skipped id to accept (whole draft's accept fails); dropping a
   create while keeping its dependent add_link miscounts the dock and the
   dropped-dependency warning misses link targets (`mutation.link.target` not
   checked). Fix: await fresh preflight in `applyDecided`, intersect
   `readyMutationIds` with current keeps, include link targets in the warning.
3. **Keyboard decisions hit invisible rows** [INT high] — cursor resolves
   against unfiltered rows; with filters on, `a`/`d` mutate filtered-out or
   even empty-list rows silently. Fix: resolve cursor against `visibleKeys`.
4. **Space/Enter on focused chips hijacked** [INT high] — `onListKey` exempts
   only INPUT/TEXTAREA/SELECT; Space on a focused filter chip cycles an
   unrelated claim's decision. Fix: bail when target is a BUTTON.
5. **`skippedMutationIds` ignored on accept** [COD high] — partial-success
   accepts mark every submitted id applied; server-rejected mutations vanish
   for the session (`appliedThisSession` never cleared). Fix: honor the field.
6. **Ledger loss windows** [INT+COD med] — no flush on
   pagehide/visibilitychange (trailing 700ms debounce loses last decisions on
   tab close), and remount within the debounce clobbers unsaved decisions via
   `loadPersisted`. Fix: flush on hide (sendBeacon); skip load while dirty.
7. **Undo-stack hygiene** [INT low + COD low] — stack survives Apply (misfires
   onto applied keys); no-op decisions push identical snapshots ("dead" first
   undo). Fix: clear on apply; skip no-op snapshots.
8. **Small server/store faults** [COD med] — malformed state PUT returns 500
   not 400; Vault archive-undo PATCH has no `.catch`; stale focus-source key
   survives a failed refresh and misfires later.

## B · Mobile fundamentals — P0/P1

9. **Tap never opens claim detail** [Eli + LNK high + MOB critical] —
   `focusRow` gates `detailKey` on desktop; the whole detail surface is
   unreachable by touch. Fix: open stacked detail on mobile tap.
10. **Hardware back exits the app** [LNK+MOB high] — stacked detail, facet
    sheet, peek push no history; Android back-swipe mid-triage leaves the
    console. Fix: overlay history integration (pairs with D27 deep links).
11. **Escape contract broken inside overlays** [INT+LNK+MOB high] — the only
    key handler sits on `.audit-list`; Esc does nothing with focus inside the
    sheet/detail, and NotePeek never closes on Esc, never traps or returns
    focus. Fix: document-level overlay stack owning Escape + focus.
12. **Density: 4 rows/screen vs ~10 target** [MOB high + Eli] — 96px of
    scaffolding (grouphead + keep/drop action row) per group, most groups
    single-row; chrome eats 26% of the screen. Fix: fold group actions into
    the head, suppress for single-row groups.
13. **Mobile chip rail → three buttons** [Eli] — [Filter] [Group by] [Sort by]
    (+ sort direction); today group/sort chips sit 1-2 screens off-canvas with
    no scroll affordance [MOB low]. Open: which quick chips survive inline
    (interview Q7).
14. **Facet sheet doesn't fit / Clear scrolls away** [Eli + MOB med] — 980px
    content in a 657px sheet; header not sticky within the sheet. Fix: sticky
    sheet header + tighter rows; consider per-facet collapse.
15. **Apply dock occludes** [MOB med] — covers the bottom tool rail entirely
    on phone (can't switch tools while decisions exist); 20px overlap onto the
    desktop rail (64px vs 84px). Fix: dock above rail on mobile; fix offset.
16. **Undo has no touch path when the dock hides** [MOB med] — dock is the
    only touch Undo and unmounts at zero tally. Fix: undo toast on bulk reset;
    keep dock while `canUndo`.
17. **Sticky groupheads hide under the console** [MOB med] — z/top collision;
    the pinned context header is invisible mid-scroll. Fix: top offset.
18. **Export glyph is tofu on phone** [MOB low] — U+2B73 not in loaded faces.

## C · Visibility of computed state — P1

19. **Preflight runs silently; button reads "(0)"** [VIS high + INT med + MOB
    low] — no pending indicator during debounce+RTT; first keep looks like
    "nothing will apply". Fix: `preflightPending` signal, "checking…" copy.
20. **Auto-included dependencies unenumerable** [VIS high + INT med] — "N
    added as dependencies" names no rows; undecided claims get sent with zero
    row-level indication, contradicting the store's own contract copy. Fix:
    expandable dock phrase + row badge "sent as dependency".
21. **Meter denominator includes undecidable claims** [VIS high + COD med] —
    header uses `counts.mutations` (includes blocked drafts' rows), dock uses
    decidable rows; same word, two numbers. Fix: `rows.value.length`.
22. **Meter is color-only** [VIS med] — "1 · 0 / 17" emerald/red; pair glyphs
    "✓1 · ✗0 / 17" (WCAG 1.4.1, DESIGN §1).
23. **Ledger state invisible at rest; failure unrecoverable** [VIS med ×2] —
    "Saved" never shows; "Save FAILED" is dim header text with no retry and no
    toast. Fix: persistent save pill + retry affordance.
24. **Blocked card names nothing** [VIS+LNK med] — source titles unused, held
    claims invisible, re-extract semantics unstated, button has no busy state
    and double-fires [INT low]. Fix: per-source rows with NoteRefs, busy
    state. (Cost confirm already in backlog.)
25. **Index health is inert** [VIS med cluster] — rebuild failure is
    toast-only (journey table wants a persistent "saved, not searchable"
    badge); no rebuild affordance anywhere; header counts stale after
    import/apply (effect keyed on view) [COD low]; status fetch failure blanks
    the line; `embeddingsAvailable:false` (dead recall lane) never surfaces.
26. **Apply progress is a button label** [VIS med] — sequential multi-draft
    loop with no per-draft progress. Fix: "draft 2/5" in the dock.
27. **Pressure numbers never reach the UI** [COD+VIS med] — full
    current/projected map computed; only a boolean chip ships. Fix: "19.4k →
    21.3k / 20k" on target group heads and in ClaimDetail; wire `nearLimit` at
    ≥0.8.
28. **Sources previews load blank; imports are a button label** [VIS med ×2] —
    render kind headers immediately with "scanning…"; stream per-source import
    results ("Importing 2/5…").
29. **Silent staleness** [VIS low] — `generatedAt` and engine dedup counts
    fetched, never shown; no refresh affordance on Review/Sources.
30. **Restore-point failure invisible** [COD med] — `x-ltm-restore-point:
    failed` header read by nobody. Fix: check in `api()`, toast once.

## D · Linkage and navigation — P1/P2

31. **Vault note → related claims missing** [LNK high] — the editor says
    "pruning here is what unblocks the queue" but offers no path to those
    claims. Fix: "related claims (n)" → review pre-filtered by target.
32. **No object has an address** [LNK med] — no `#/memory/vault/:noteId` or
    review claim deep links; root cause of the back-button trap, peek
    dead-ends, and Cmd-K having nothing to target.
33. **NotePeek dead-ends** [LNK med ×3] — no open-in-vault, no back stack for
    chained peeks, no reverse-links section ("what came from this source?" —
    all notes already client-side).
34. **create_note target is a dead 404 link** [LNK med] — peek the *proposed*
    note from `m.note`, or render "will be created".
35. **Sources never links onward** [LNK med] — outside the transient import
    card: no pending-drafts count → review handoff, no NoteRef to the imported
    source note; the word "review" absent from the surface.
36. **Review tab click wipes facets** [LNK med] — hidden destructive side
    effect on a nav control. Remove; ship removable filter chips instead
    (with 37).
37. **Active filters invisible outside the sheet** [LNK med] — the handoff
    filter shows only "7 of 17"; render active facet values as removable
    chips (DESIGN §4).
38. **Vault forgets everything on tab round-trip** [LNK med] — useState vs
    Review's signals; the prune-then-retry errand pays twice. Hoist to
    signals.
39. **Small linkage** [LNK low ×3] — group heads not linked to their object;
    status-line counts navigate nowhere; restates link shows raw id not title.

## E · Copy and semantics — P2

40. **Tab badge counts drafts, shown next to claim counts** [Eli + COD] —
    show pending claims to match the meter.
41. **Wrong-journey empty states** [VIS med ×2 + INT med] — Review empty state
    uses a Sources string; Vault zero-result search shows the "vault is empty"
    onboarding; facet sheet can render fully blank (active zero-count values
    dropped — also makes filters un-clearable individually).
42. **"N will be sent · M stay pending" double-counts** [VIS+INT med] — same
    draft in both numbers; rephrase "sent partially; undecided stays pending".
43. **Vault promises "create a memory manually"** [COD med] — no create
    affordance exists (and no POST /notes binding). Swap copy or build it.
44. **Permanent-delete confirm uses source-note copy for every type** [COD
    med] — "keep its extracted memories" is false for a character note.
45. **Staged-edit toast says "Saved"** [VIS low] — say "Edit staged — applies
    with the batch"; also: edited text not rendered in the row, dropping an
    edited claim silently discards the edit and still counts it [INT low].
46. **"Discard changes" destroys the edit with no undo** [INT med] — route
    through undo or toast the discarded text.
47. **Freshness chips / "N ready" unmapped** [VIS med ×2] — chips name states
    not obligations; "3 scanned · 1 ready" maps to no row marking.
48. **Chat-summaries zero explains the feature, not the zero** [VIS med] —
    J1's "explain the emptiness and when to return".
49. Small copy: "23 match" pluralization; RESTATES bare score on rows; undo
    toast wording/stacking; hardcoded "over the limit" bypassing OURS [COD].

## F · A11y depth — P2

50. **No roving tabindex** [MOB high + INT low] — ~74 tab stops to cross the
    list; DESIGN §3 mandates one stop per composite.
51. **No `?` cheat sheet** [MOB+INT med] — the a/d/x/space/u vocabulary is
    taught only by the empty detail pane.
52. **Focus ring invisible on active rail item** [MOB med] — specificity bug.
53. **Dialog semantics incomplete** [MOB low] — no aria-modal, no focus
    move-in/restore; stack-screen has no role; badge concatenates into tab's
    accessible name ("Review Queue2").
54. **Desktop detail pane can't be closed and goes stale under filters**
    [INT low].
